💰 MoneyTracker Backend

Серверное приложение на языке C++ для учета личных финансов, управления счетами, категориями, пользователями и транзакциями, с поддержкой REST API, системы авторизации, гибкой фильтрации и вебхуков для интеграции с банковскими сервисами на базе СУБД PostgreSQL.
🛠 Технологический стек

    Язык программирования: C++17

    Система сборки: CMake (версия 3.15+)

    СУБД: PostgreSQL

    Библиотека работы с БД: libpqxx (официальный C++ драйвер PostgreSQL)

    HTTP-сервер / REST API: cpp-httplib

    Парсинг JSON: nlohmann_json

📂 Структура проекта
Plaintext

.
├── CMakeLists.txt        # Скрипт сборки проекта и управления зависимостями
└── money_tracker.cpp    # Исходный код сервера, логика БД и обработка HTTP-запросов

⚙️ Системные требования

Перед сборкой проекта убедитесь, что в вашей операционной системе установлены:

    Компилятор с поддержкой стандарта C++17 (например, g++ или clang).

    Система автоматизации сборки CMake (v3.15+).

    СУБД PostgreSQL и библиотека libpqxx.

🚀 Инструкция по сборке и запуску

    Создайте папку для сборки и перейдите в неё:
    Bash

    mkdir build
    cd build

    Запустите конфигурацию CMake:
    Bash

    cmake ..

    Скомпилируйте проект:
    Bash

    cmake --build .

    Запустите исполняемый файл:
    Bash

    ./MoneyTracker

🔌 Описание API Эндпоинтов
1. Авторизация и пользователи (Auth)

    Регистрация пользователя

    Метод: POST

    Путь: /api/v1/auth/register

    Тело запроса (JSON):
        JSON
        {
          "username": "viktoria",
          "password": "123"
        }

    Вход в систему

    Метод: POST

    Путь: /api/v1/auth/login

    Тело запроса (JSON):
  JSON
        {
          "username": "viktoria",
          "password": "123"
        }

2. Счета (Accounts)

    Получение списка всех счетов

        Метод: GET

        Путь: /api/v1/accounts

    Создание нового счета

        Метод: POST

        Путь: /api/v1/accounts

        Тело запроса (JSON):
        JSON

        {
          "name": "Основная карта",
          "balance": 150.0,
          "currency": "BYN"
        }

3. Категории (Categories)

    Получение списка категорий

        Метод: GET

        Путь: /api/v1/categories

    Добавление новой категории

        Метод: POST

        Путь: /api/v1/categories

        Тело запроса (JSON):
        JSON

        {
          "name": "Продукты",
          "type": "expense",
          "target_percentage": 30.0
        }

4. Транзакции и независимая фильтрация

    Получение списка транзакций

        Метод: GET

        Путь: /api/v1/transactions

        Query-параметры (необязательные, работают независимо друг от друга):

            ?date=2026-11 — фильтрация по дате/году/месяцу

            ?amount=-45.5 — фильтрация по точной сумме

            ?category=Продукты — фильтрация по названию категории (или ID)

        Пример запроса с комбинацией фильтров:GET /api/v1/transactions?date=2026-11&category=Продукты

5. Банковские вебхуки

    Автоматическая обработка входящей транзакции от банка
    Принимает информацию об операции, сохраняет её в базу, обновляет баланс счета и проверяет превышение месячного лимита по категории. Если это поступление зарплаты, автоматически пересчитываются бюджетные лимиты.

        Метод: POST

        Путь: /bank-webhook

        Заголовки: Content-Type: application/json

        Тело запроса (JSON):
        JSON

        {
          "account_id": 1,
          "category_id": 2,
          "amount": -45.50,
          "description": "Оплата покупок в супермаркете"
        }

        Варианты ответов сервера:

            200 OK — Транзакция успешно записана и обработана ({"status": "ok", "message": "Transaction processed"}).

            400 Bad Request — Передан некорректный формат JSON.

            500 Internal Server Error — Ошибка взаимодействия с базой данных PostgreSQL.
