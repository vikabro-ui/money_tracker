# 💰 MoneyTracker Backend

Серверное приложение на языке **C++** для учета личных финансов, управления счетами, категориями и транзакциями, с поддержкой **REST API вебхуков** для интеграции с банковскими сервисами и реляционной базой данных **PostgreSQL**.

---

## 🛠 Технологический стек

* **Язык программирования:** C++17
* **Система сборки:** CMake (версия 3.15+)
* **СУБД:** PostgreSQL
* **Библиотека работы с БД:** `libpqxx` (официальный C++ драйвер PostgreSQL)
* **HTTP-сервер / REST API:** `cpp-httplib` (автоматическое подключение через `FetchContent`)
* **Парсинг JSON:** `nlohmann_json` (автоматическое подключение через `FetchContent`)

## ⚙️ Системные требования

Перед сборкой проекта убедитесь, что в вашей операционной системе установлены:
1. Компилятор с поддержкой стандарта C++17 (например, `g++` или `clang`).
2. Система автоматизации сборки **CMake** (v3.15+).

## 🔌 Описание API Эндпоинтов

### Обработка банковских вебхуков
Принимает информацию о проведенных операциях, сохраняет транзакцию в базу данных и производит автоматическую проверку на превышение установленного месячного лимита по выбранной категории.

* **Метод:** `POST`
* **Путь:** `/bank-webhook`
* **Заголовки:** `Content-Type: application/json`
* **Тело запроса (JSON):**
  ```json
  {
    "account_id": 1,
    "category_id": 2,
    "amount": -45.50,
    "description": "Оплата покупок в супермаркете"
  }
  ```

#### Варианты ответов сервера:
* **`200 OK`** — Транзакция успешно записана и обработана.
  ```json
  {
    "status": "ok",
    "message": "Transaction processed"
  }
  ```
* **`400 Bad Request`** — Передан некорректный формат JSON.
* **`500 Internal Server Error`** — Ошибка взаимодействия с базой данных PostgreSQL.
